# 🧭 Politics-view

یک اپلیکیشن وب تعاملی برای سنجش گرایش‌های سیاسی (اقتصادی و اجتماعی) که با **React.js** طراحی و توسعه داده شده است. این پروژه به کاربران کمک می‌کند تا در محیطی ساده و سریع، دیدگاه سیاسی خود را ارزیابی کنند.

## 🚀 ویژگی‌ها

- **تکنولوژی مدرن:** استفاده از React برای مدیریت بهینه وضعیت (State) و کامپوننت‌ها.
- **طراحی سبک:** تجربه کاربری روان بدون رندرینگ‌های اضافه.
- **ریسپانسیو:** نمایش صحیح در موبایل، تبلت و دسکتاپ.

## 🛠 تکنولوژی‌های استفاده شده

- **Frontend:** React, JavaScript (ES6+), CSS3
- **Deployment:** Vercel

## ⚙️ نحوه اجرا در سیستم شخصی (Development)

برای اجرای پروژه روی سیستم خود مراحل زیر را دنبال کنید:

1. **کلون کردن ریپازیتوری:**

```bash
   git clone https://github.com/streaverson/Politics-view.git
   cd Politics-view

```

2.**نصب وابستگی ها**

```bash
   npm install
```

2.**اجرای پروژه**

```bash
   npm start

```
